# Rose Designs — Interior Design Portfolio

A responsive, static portfolio website for **Eman Mohamed Ahmed Abbas**, designed for free hosting on GitHub Pages.

## Design direction

Editorial / Behance-inspired long-form portfolio with large project imagery, strong typography and concise case-study storytelling.

**Hero claim:** “Beautiful isn’t enough.”  
**Supporting line:** “I design spaces that work first — then make them unforgettable.”

## Stack

- HTML5
- CSS3
- Vanilla JavaScript
- No build step
- GitHub Pages ready

## Local preview

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## GitHub Pages

1. Create a **public** repository, suggested name: `rose-designs-portfolio`.
2. Upload all files from this folder to the repository root.
3. In GitHub, go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then save.
6. GitHub will display the live URL after deployment.
